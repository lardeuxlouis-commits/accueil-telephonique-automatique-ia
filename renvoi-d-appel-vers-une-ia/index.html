Renvoi d'appel vers un agent IA : comment le configurer (mobile, ligne fixe, box)

Brancher un agent IA sur votre ligne ne demande ni nouveau numéro ni matériel : un simple renvoi d'appel suffit. Voici les codes, les réglages et les pièges, selon que vous êtes sur mobile, sur ligne fixe ou sur un standard.

Par Louis LardeuxMis à jour le 5 octobre 20267 min de lecture
L'essentiel
  • Le renvoi sur non-réponse (**61*) est le plus utilisé : l'agent décroche quand vous ne le faites pas.
  • Sur un mobile, les codes sont normalisés et valables chez tous les opérateurs. Annulez avec ##002#.
  • Quatre ou cinq sonneries, soit vingt à vingt-cinq secondes, sont un bon repère.
  • Sur une ligne fixe professionnelle, les codes mobiles ne marchent pas toujours : demandez le renvoi à l'opérateur.
  • Testez toujours avec un vrai appel avant d'annoncer quoi que ce soit.

Quel type de renvoi choisir : toujours, sur non-réponse ou sur occupation ?

Pour brancher un agent IA sur votre ligne, vous activez un renvoi d'appel vers le numéro de l'agent. Il existe trois grands types de renvoi, et le choix dépend du moment où vous voulez que l'agent intervienne.

Type de renvoiL'agent décroche quand…Pour quel usage
Inconditionnel (tous les appels)Toujours, sans que votre téléphone sonneFermeture, congés, soirée : vous ne voulez être dérangé par aucun appel
Sur non-réponseVous ne décrochez pas après quelques sonneriesLe cas le plus courant : l'agent prend le relais quand vous êtes absent ou en rendez-vous
Sur occupationVous êtes déjà en ligneÉviter que le second appelant tombe sur un signal d'occupation
Si injoignableVotre mobile est éteint ou hors réseauCompléter les autres renvois pour ne jamais laisser un appel sans réponse

Dans la plupart des cas, on combine le renvoi sur non-réponse et le renvoi sur occupation : vous gardez la main, et l'agent n'intervient que si vous n'êtes pas disponible. Le renvoi inconditionnel est réservé aux moments où personne ne veut décrocher.

Quels codes composer sur un mobile pour renvoyer vers un agent IA ?

Sur un mobile, les renvois s'activent avec des codes normalisés (norme GSM). Ils fonctionnent de la même manière chez Orange, SFR, Bouygues Telecom et Free. On compose le code sur le clavier du téléphone, comme un numéro, puis on valide l'appel.

ActionCode à composerRemarque
Renvoi de tous les appels**21*numéro#Inconditionnel : votre téléphone ne sonne plus
Renvoi sur non-réponse**61*numéro#Le plus utilisé pour un agent IA
Renvoi si injoignable**62*numéro#Mobile éteint ou hors réseau

Dans les codes, « numéro » est celui de l'agent. Saisissez-le au format international (+33…) pour éviter les erreurs d'interprétation. Après chaque activation, l'opérateur affiche un message de confirmation : lisez-le avant de fermer l'écran.

Attention

Ces codes sont un standard, mais certains abonnements ou certains opérateurs adaptent leur comportement. En cas de doute, consultez l'aide de votre opérateur ou son espace client.

Combien de sonneries laisser avant le renvoi ?

Le renvoi sur non-réponse s'enclenche après un nombre de secondes de sonnerie. Une sonnerie dure environ cinq secondes en France, silence compris, donc quatre ou cinq sonneries représentent vingt à vingt-cinq secondes. Chez plusieurs opérateurs, la durée par défaut se situe autour de vingt secondes.

Le réglage tient en un arbitrage simple : trop court, l'agent décroche avant que vous ayez eu le temps de répondre ; trop long, l'appelant s'impatiente et raccroche avant l'agent.

  • Si vous répondez vous-même quand vous le pouvez : quatre ou cinq sonneries laissent le temps de décrocher.
  • Si l'appel est rarement pris : réduisez, l'agent fera gagner du temps à l'appelant.
  • Si votre ligne sonne dans plusieurs postes : laissez plus de temps pour que quelqu'un ait la chance de décrocher.

Selon l'opérateur, la durée peut se préciser dans le code en ajoutant un nombre de secondes à la fin. La syntaxe exacte varie d'un opérateur à l'autre : suivez l'aide de votre opérateur, ou un guide comparatif comme celui de Selectra sur le délai de sonnerie.

Pourquoi le répondeur de l'opérateur décroche-t-il avant le renvoi ?

C'est un piège classique. Sur un mobile, la messagerie vocale de l'opérateur peut répondre avant que votre renvoi sur non-réponse se déclenche. L'appelant entend alors le répondeur de l'opérateur, et l'agent IA ne reçoit jamais l'appel.

Pour l'éviter, vérifiez deux choses. D'abord, que la messagerie vocale n'est pas réglée pour répondre plus vite que votre renvoi. Ensuite, que le délai avant renvoi est inférieur au délai avant la messagerie. Certains opérateurs permettent de désactiver complètement la messagerie vocale, ce qui règle le problème.

Après tout changement, refaites un test réel : laissez sonner le téléphone depuis un autre numéro et notez qui répond.

Comment faire sur une ligne fixe professionnelle, une box ou un standard IP ?

Les codes ci-dessus sont conçus pour les mobiles. Sur les autres lignes, le renvoi se règle autrement.

  • Ligne fixe d'un opérateur professionnel : le renvoi se demande à l'opérateur ou se règle dans son espace client. Les codes pour mobiles ne fonctionnent pas toujours.
  • Box grand public : le renvoi se règle généralement depuis l'espace client, ou avec un code propre à l'opérateur.
  • Standard IP ou téléphone de bureau IP : le renvoi sur non-réponse est un réglage du standard ou de l'appareil, avec une temporisation en secondes.

Un cas rencontré sur le terrain, rendu anonyme : une auto-école de plusieurs agences, avec des lignes fixes d'un opérateur professionnel. Les codes de renvoi des mobiles n'ont pas fonctionné. Il a fallu demander directement à l'opérateur un renvoi sur non-réponse, activé après quatre ou cinq sonneries, pour chacun des numéros.

À retenir

Pour un groupe avec plusieurs agences, demandez un renvoi par numéro d'agence. Chaque agence garde son numéro, et l'agent répond en connaissant l'agence appelée.

Un renvoi vers un agent IA coûte-t-il quelque chose ?

Le service de renvoi d'appel est en général inclus dans les abonnements. Ce qui peut coûter, c'est l'appel renvoyé lui-même : selon l'opérateur, le forfait et le type de numéro, il est décompté de votre forfait ou facturé comme un appel vers un numéro externe. Certains opérateurs facturent explicitement le renvoi vers un numéro externe, d'autres l'incluent.

Avant de brancher quoi que ce soit, regardez la ligne « renvoi d'appel » ou « appels vers numéros fixes et mobiles » de votre forfait, et demandez-le à votre opérateur si elle n'est pas claire. Le prestataire de l'agent IA facture de son côté les minutes d'appel qu'il traite : les deux coûts s'additionnent.

Comment tester le renvoi avant de l'annoncer à vos clients ?

Un renvoi mal réglé ne se voit pas : l'appelant tombe sur un répondeur ou une sonnerie sans fin, et vous ne le savez jamais. Cinq tests suffisent.

  1. Appel simple. Appelez votre numéro depuis un autre téléphone, laissez sonner, notez au bout de combien de secondes l'agent décroche.
  2. Appel pendant une communication. Pendant que vous êtes en ligne, faites-vous appeler : l'agent doit décrocher si vous avez activé le renvoi sur occupation.
  3. Appel depuis un autre opérateur, pour vérifier que le renvoi fonctionne quel que soit l'appelant.
  4. Lecture du compte rendu. Vérifiez que le numéro de l'appelant y figure bien, et non le vôtre.
  5. Appel à un moment d'affluence. L'agent doit tenir quand plusieurs appels arrivent à la suite.

Comment annuler ou suspendre le renvoi d'appel ?

Un renvoi reste actif tant que vous ne l'annulez pas, même si vous changez de téléphone : c'est un réglage du réseau, pas de l'appareil. Pour l'arrêter :

  • Sur un mobile : composez ##002# pour tout effacer, ou le code d'annulation du type de renvoi voulu (##61# pour la non-réponse, par exemple).
  • Dans l'espace client de l'opérateur, qui affiche l'état des renvois.
  • Auprès de l'opérateur pour les lignes fixes professionnelles.

Pensez à noter les codes utilisés et la date d'activation. Le jour où vous changez d'agent, de numéro ou de prestataire, vous saurez quoi modifier.

Questions fréquentes

Quel code utiliser pour renvoyer mes appels vers un agent IA quand je ne réponds pas ?

Le code de renvoi sur non-réponse est **61* suivi du numéro de l'agent, puis #. Pour le renvoi sur occupation, c'est **67* suivi du numéro et de #. Ces codes sont un standard mobile, vérifiez-les ensuite avec *#61# et *#67#.

Mon numéro de téléphone change-t-il avec un renvoi d'appel ?

Non. Le renvoi redirige les appels entrants sans modifier votre numéro. Vos clients continuent d'appeler le même numéro, et l'agent répond à votre place quand vous ne décrochez pas.

Pourquoi mon renvoi d'appel ne fonctionne-t-il pas ?

Les causes fréquentes : la messagerie vocale de l'opérateur répond avant le renvoi, le numéro de destination est mal saisi, ou la ligne est une ligne fixe professionnelle sur laquelle les codes mobiles ne s'appliquent pas. Testez avec un appel réel et contrôlez avec *#61#.

Puis-je renvoyer plusieurs numéros vers le même agent ?

Oui, dans la plupart des cas, chaque numéro étant renvoyé séparément. Pour un groupe, il est préférable qu'un numéro d'agence soit associé à une accroche qui nomme cette agence.

Comment désactiver le renvoi d'appel ?

Composez ##002# pour effacer tous les renvois, ou ##61# pour la seule non-réponse. Sur les lignes fixes et les box, passez par l'espace client ou l'opérateur.
